## 已实现的空间与运动

大尺度梁体、中尺度的重复层面、较细的连接构件分别成组。侧向、横向和上方层面交错布置，开口延伸到不同的纵深；构图经过正视、两侧、抬头和回望检查。部分嵌套结构仍需在后续艺术审阅中调整密度与重量。

主结构采用固定四维顶点与连接数据，活动层面的交点与相邻层连接共享顶点标识。整组结构进行 XW 正交旋转并投影到三维；梁体厚度和倒角属于投影后的三维渲染表现，不声称是严格的四维实体截面。

每次只有一个主要结构组发生折叠。自动稳定期 72 秒；预兆 8 秒、折叠 24 秒、落定观察 10 秒。折叠达到新角度后保持该状态，下一次事件从现有角度开始，可以反向回到初态。没有独立的随机单元相位，也不通过缩细或消隐解决镜头穿模。

保留原有基于时间间隔的前进与弹性扭头控制，主镜头仍只有一个写入者。拖拽、方向键、回望和「看向前方」可操作。「暂停前进」只控制位移，「定格结构」控制结构时钟。手动观看折叠不转动镜头。失焦停止时间推进，恢复不补跑；减少动画时默认关闭自动运动，用户可手动切换结构状态。

采用中性灰材质、实体侧面、基础阴影和少量深处暖白光面；关闭 Bloom，没有粒子。主光阴影覆盖随可见空间段更新，当前属于预览照明。最终材质、光源布局与细腻光影仍需继续精修。

## 运行组织

7 个 48 单位的空间段复用，保留镜头后方 2 段。每段使用相同的结构规则和确定布局；新增远段进入时处于远景衰减范围内。折叠角度状态在远离可见范围后回收。

首轮固定资产：主梁 70、层面构件 1813、连接构件 840、暖白光面 7。共享 1 个倒角箱体几何；材质按构件类别复用。稳定阶段缓存投影和实例矩阵，仅变化的结构组重新计算，避免整场景每帧重建。

实现位于 src/mathverse/experiments/layered/spaceModel.ts、Megastructure.tsx、SpaceStudy.tsx 和 spaceStudy.css。主入口新增 /space-a/ 分支，新样片按需加载。没有新增依赖或软件，项目、临时文件、检查输出和录像均在 D 盘。

## 实际验证

1. `npm run build`：通过类型检查与生产构建。原有大体积主包提示仍存在，未将本轮称为加载性能优化完成。
2. `npm run test:space-a`：105 个折叠角度覆盖完整范围。按梁体包围半径保守计算，路线最小净空约 5.162 单位，高于 3.2 的预览目标；投影分母最小约 18.239，没有投影奇点。活动结构 756 个共享连接顶点通过连接检查。
3. 30／60／120Hz 模型模拟：20 秒时角度一致，43 秒后落定为 0.52 弧度。冻结状态不推进；模拟 1000 段位置迁移后角度缓存有界。
4. 原有运动内核检查：前进距离、弹性扭头、角度边界、速度衔接和恢复检查通过。
5. `npm run test:space-a-browser`：电脑原有 Edge 中完成前进、真实鼠标拖拽、五个视角、一次完整折叠、结构定格与恢复、失焦与恢复、减少动画以及原主页推门入场。无页面异常。单次折叠前后几何数量保持 1、纹理数量保持 3。
6. 1280×720、1440×900、1920×1080 下完成操作边界与截图检查。随后在内置浏览器检查实际画面，将控制集中在左下方，以适合较窄的桌面面板。末次布局中四个按钮的横向范围为 298–667px，返回入口为 312–389px。
