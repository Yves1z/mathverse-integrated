# 巨构空间尺度返修

用户认为上一版空间狭小，本轮优先改造空间本身。沿用早期层叠巨构的语法，把有限房间的感受调整为跨越视野的多层结构。

## 构成

- 中央通道两侧向外拉开，纵向节距由 48 调整为 216；高度按 4.2 倍重排。梁柱截面只放大 1.4–2.4 倍，保留厚重近景，同时扩大结构之间的虚空。
- 加入上下相隔 280 的结构层，以及左右相隔 430 的侧向结构库。所有层沿用同一个节距、同一静态秩序，环顾时看到主通道之外的延续。
- 保留七段随前进循环的巨构。相邻循环区间保留相同顶点与构件，不因空间扩展产生断缝。
- 欧拉单元移到侧前方 [-128, 14, -190]；数学源、体积外壳、纸面与连接仍共用四维投影。均匀放大 2.2 倍，内外交换的线性尺寸比仍为 3.22。

## 光影与运动

雾密度由 .017 改为 .0024，远裁剪面由 180 改为 1500。清晰近景、中景银灰与远景衰减共同建立尺度。主光方向和强度保持稳定，阴影覆盖随前进按光空间像素对齐。区域光随结构的 216 节距布置，避免闪烁。

继续使用缓慢深入、弹性环顾、32 秒初始稳定、80 秒后续稳定、6／30／8 秒局部事件。阅读维持 80.1% 面积与 6% 非零慢行。本轮没有增加独立翻转或随机动态。
