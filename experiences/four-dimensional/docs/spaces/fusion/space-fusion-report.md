# 空间融合样片实施记录

2026-10-11。新增 `/space-fusion/` 与 `/space-fusion/worlds/`，原主页、原四维单模型及体积交换样片保持可访问。

## 已实现的构成

- 一个欧拉单元，侧后方与上方两处静态参照，共三个源超立方体；每处仍保留 16 个顶点与 32 条边。
- 欧拉单元使用完整单位圆与有限螺旋面，所有源顶点沿同一个 XW 旋转与中央投影；没有附加独立缩放。端点投影线性尺度约 3.2222 倍。
- 12 条连接直接绑定投影顶点与外围骨架角点，受同一主时钟控制。整体共有 184 条实体结构梁及 6 条短暖白标记，使用固定实例缓冲。
- 外围骨架使用 10 个有界复用截面，主体与两处参照身份固定。距离雾密度 0.0038，沿用稳定受光方向、石墨灰表面与真实深度遮挡。
- 静止 60 秒，事件 6／30／8 秒，一次只有欧拉单元参与主要翻转。持续前进与弹性环顾独立于翻转。
- 真实图形可点击进入约 80.1% 阅读区域，外围继续以 6% 非零速度前进；返回恢复先前暂停状态。索引中的六个阅读世界仍可访问。

## 验证结果

`scripts/spaces/fusion/space-fusion.model.test.mjs` 检查 722 个角度，包括退化切片角。投影、连接与短光线端点均为有限值，连接起点精确等于所属源顶点的投影；两个参照单元不变。数学源顶点保持不变，Float32 投影最大误差约 9.54e-7。主时钟模拟 20 分钟，只保留欧拉单元的角度状态。

`scripts/spaces/fusion/space-fusion.browser.test.mjs` 用 Edge 实际运行一次完整翻转，并通过鼠标输入检查环顾、真实圆弧点击、阅读与关闭、桌面显示、新旧入口及旧版空间。固定眼点下，投影半径比 3.2222222，单位圆保守屏幕包围框宽比 3.2762、高比 3.3907。两处参照不动，周围连接跟随变化。结构定格的截图像素一致。

六次阅读前后资源保持 31 个几何体、16 张纹理，浏览器错误为空。1280×720 与 1920×1080 阅读区域保持约 80.1%。构建、原体积投影检查与原有序空间模型检查通过。

对照页三个按钮与图片加载通过。实录时长 104.72 秒，在内置浏览器中实际播放后进度正常增加，媒体错误为空。减少动态设置下默认停止旅程及结构变化，手动交换和阅读仍可使用；见 `scripts/spaces/fusion/space-fusion.qa.mjs` 与 `artifacts/spaces/fusion/space-fusion/gallery-and-reduced-motion.json`。

实录、对照截图与 JSON 结果位于 `artifacts/spaces/fusion/space-fusion/`。改前完整源码位于 `artifacts/spaces/fusion/space-fusion/source-baseline/src/`。

## 范围与后续

这是一份三处固定单元的构成样片，外围骨架可以继续延伸。它没有实现无限流式的已填充数学世界；后续需结合本轮审美反馈设计新的世界及其出场关系。长时间真实浏览器运行与指定电脑上的 GPU 帧率验收尚未进行。跨单元骨架是艺术性的三维连接，不声称所有结构构成一个严格四维刚性物体。

运行：先加载 `Enter-Environment.ps1`，然后 `npm run test:space-fusion`、`npm run test:space-fusion-browser`、`npm run build`。
