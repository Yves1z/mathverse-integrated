## 构成与几何

右前方新增一个固定源单元，中心 [76,-24,-182]、朝向 -0.9、投影尺度 16。共有四个源单元：欧拉、莫比乌斯、高斯及静置的侧后方参照。外围保持十个有界复用截面，226 个实例中 220 条实体梁、6 条暖白短标记；16 条连接精确绑定投影源顶点与外围角点。

高斯曲面源顶点为 [r cosθ,-0.28+0.62 exp(-(r/0.28)²),r sinθ,-1]，r∈[0,0.69]。主体为 12289 个顶点、24384 个非退化三角形；中心单顶点扇避免峰顶产生重复退化面，周向索引焊接。银色曲面、固定方位 1.05 的暖白截线、细圆边界逐点使用所属骨架的 XW 投影，没有额外缩放或独立旋转。近退化角时曲面淡出，截线和边界保留。

这里是经过展示坐标缩放和平移的有限高斯曲面片段，不声称眼前有限曲面完整展示无限积分，也不将曲面高度解释为归一化概率密度。阅读保留既有全轴高斯积分、径向积分与极坐标解释，NIST DLMF 7.2 的定义与实轴极限已核对。

序列为 0 欧拉、1 莫比乌斯、2 高斯展开，然后依次收回。首次稳定 20 秒，之后 60 秒；事件 6／30／8 秒，一次只有一个主要单元运动。侧后方不参加翻转。持续前进、弹性扭头、定格和减少动态继续保持。
