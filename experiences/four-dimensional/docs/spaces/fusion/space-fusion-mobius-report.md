# 第二个体积世界实施记录

2026-10-11。新增 `/space-fusion/mobius/` 和 `/space-fusion/mobius/worlds/`；上一轮融合、根主页及所有历史样片入口保留。

上方源单元包含半扭转莫比乌斯曲面、单一闭合边界及暖白光点。源曲面半径 0.52、半宽 0.14，采用固定斜置角度以辨认扭转。源参数接缝反向对应，渲染网格在接缝复制局部法线；边界以一个 4π 参数周期闭合。边界管径 0.0085，光点沿共享角度的两倍运行，不引入独立随机动画。

曲面、边界和光点逐顶点使用所属骨架的 XW 旋转与中央投影。近退化切片时曲面淡出，边界保持。体积尺度以单元中心到实际顶点的最大距离统计，避免轴对齐包围球中心变化影响端点尺度核对。

欧拉与莫比乌斯依次展开、收回，侧后方静置。12 条外部连接跟随各自投影顶点。首次稳定 20 秒，此后稳定 60 秒；事件 6／30／8 秒，一次只有一个主要单元翻转。保持石墨骨架、银色曲面及少量暖白边界，外部无新增粒子或 Bloom。

## 验证

`space-fusion-mobius.model.test.mjs` 核对反向接缝、4π 单边界周期、361 个连续投影角度、源几何不变及单元内界限。曲面投影最小分母约 0.7285；端点真实半径比约 3.2222223。逐角度检查 190 个结构实例与上方连接端点的有限性和准确对应。8 次主事件序列为 0、1、0、1、0、1、0、1，每次只有一个单元运动。原融合、体积、有序结构模型回归检查通过。

`space-fusion-mobius.browser.test.mjs` 在 Edge 1600×900 实际运行欧拉与莫比乌斯的两个完整翻转。检查真实莫比乌斯曲面点击、约 80.1% 阅读区域、外围 0.021 的非零慢行、阅读角度键盘调整与关闭后恢复先前朝向和暂停状态。检查固定眼点下的端点放大、稳定参照、连接跟随、结构定格像素一致及几何／纹理资源稳定。减少动态下默认暂停，可按固定序列瞬时切换四次；白色拱门与旧融合入口可用。

最终浏览器检查通过，真实顶点半径比 3.222222313355084，几何体 34、纹理 16，错误为空。两次实际事件顺序为单元 0、单元 1。

对照页三个按钮和真实图片加载通过；连续实录 119.8 秒，实际播放 0.79 秒后进度增加、未暂停，媒体错误为空。内置浏览器复核图片与媒体元数据，并打开新实时空间确认渲染及控制可用。

实际结果、对照图片和连续录屏位于 `artifacts/spaces/fusion/space-fusion-mobius/`；对照页为同目录 `index.html`。原始改前源码保存在 `source-baseline/src/`。模型、浏览器和对照页 QA 的 JSON 分别记录具体通过项、资源与媒体状态。最终构建通过，现有主包体积提示仍保留，后续正式集成可再拆分资源。
