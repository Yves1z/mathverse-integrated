## 构成与运动

六个单元交替位于中央路线两侧。每个单元保留原模型的固定 16 个顶点、32 条边与 XW 中央投影；局部尺度设为 16，左右偏置 72，纵深间距 108。192 条单元原生梁与 10 条上下连接合计 202 条结构梁；另有 36 条短暖白光缝追踪固定源角。连接收敛为每对相邻单元上下各一条，减少穿越数学画面的细线。

仅一条结构时钟：入场先稳定 20 秒，预兆 6 秒、主翻转 30 秒、落定 8 秒；此后每次稳定 60 秒。固定眼点的事件顺序为近处、下一处、近处回归、下一处回归。同一时刻仅一个单元改变角度，邻居保持状态；上下连接的端点同步跟随。翻转采用最小跃度曲线，没有独立随机相位或灯光明暗呼吸。

摄像头持续沿中央轴以 0.35 单位/秒前进，保持世界竖直方向，拖拽只改变观察方向。三段结构留在身后，当前及前方保留三段，原有实例缓冲循环复用。左右身份随段落编号固定。结构时钟减速与摄影速度分开处理，暂停、定格与失焦不会补跑。

## 数学窗口与阅读

欧拉恒等式、单位圆、复数旋转放在同一源面；欧拉人物、高斯积分、莫比乌斯带放在下一单元。六窗中心、方向和尺度依附 w=-1、z=1 的源面。内层源单元翻到外侧时，窗口随它展开。矩形朝向中央通行区域，掠视角逐渐淡出；悬挂线端点顺序随矩形方向修正，避免内外交换后两线交叉。标签仅强调当前可观察的两项，前景骨架参与遮挡判断与实体拾取。

三扇欧拉数学窗共享角度，人物保留无穷与圆、城市与关系、指数与旋转三章。阅读画面占视窗面积 80.1%，周边继续显示外部空间；摄影降至 6%，即 0.021 单位/秒，结构时钟降至 18%。退出后恢复原有朝向和旅程暂停状态。局部数学微尘与短轨迹保留，外部空间粒子为零。

## 光影

沿用已批准模型的倒角梁截面和细腻石墨表面，清晰区分受光宽面、背光侧面与深黑空隙。反射环境为程序化生成，主光方向固定，暖白仅用于短光缝；曝光固定为 1，关闭空间 Bloom。主阴影覆盖随摄影移动并按纹素对齐，亮度不随每个单元随机起伏。

## 验证结果

`npm run test:ordered-space` 检查 721 个角度、六个单元的固定连接、中央通行半空间、独立邻接角度的桥梁净空、窗口源面跟随、悬挂顺序、段落复用、单事件顺序与暂停。最小横向距离约 9.421，扣除最宽梁体半径后净空约 8.390；上下连接距眼高平面的最小距离约 9.173。CPU 的 30 分钟调度模拟运行 18 个事件，稳定状态占 57.79%，角度缓存最多六段。该模拟用于验证节奏和有界数据，并不代表浏览器长时间 GPU 运行。

`npm run test:ordered-space-browser` 使用现有 Edge 155.0.4283.45 实际操作：主页推门、拖拽与回望、真实窗口点击、阅读非零慢行、欧拉城市与关系章节、六窗开关、完整 44 秒事件、定格像素、失焦恢复、减少动态的手动切换。1280×720、1440×900、1920×1080 的控件和 80.1% 阅读布局通过。六次阅读前后预热资源同为 107 个几何资源、20 个纹理资源，页面异常和控制台错误为空。完整事件中只一个单元移动，窗口位置随之变化，最后角度为 π。

`npm run build` 类型检查和生产构建通过。主包约 1.789 MB、压缩约 543 KB，保留构建的大包提示；拆分优化和指定测试电脑上的 GPU 帧时间、长时间浏览器运行属于后续阶段 E 验收。

机器记录：artifacts/spaces/inversion/ordered-inversion/model-verification.json、browser-verification.json；真实截图与 ordered-space-demo.webm 位于同目录。

## 几何边界与接入范围

严格四维中央投影用于每个源超立方体的顶点和边。倒角实体梁属于三维渲染截面；跨单元连接是共享端点的三维空间构成；窗口矩形采用投影源面的局部切线近似。六个单元组成可探索的连续场景，不将整个三维构图称为一个严格四维刚体。

当前修改为 D:\Mathverse 的主页原型，未修改正式 mathweb 的业务代码或依赖。旧实验的专用检查继续对应其旧入口，新主页应使用本报告中的两项检查。
