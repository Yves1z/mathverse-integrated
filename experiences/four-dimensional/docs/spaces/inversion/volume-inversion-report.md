# 图形进入方体体积：实施与实际验证

日期：2026-10-10。用户提出图形应存在于内方体中，随翻转来到外方体，并在视野里明显变大。本轮已将欧拉单元改为体积示范，直接应用到 /space-inversion/worlds/ 和根主页白色拱门后的空间。其余三扇窗口保留，六项数学阅读和欧拉三章继续可用。

## 实际成果

演示入口：http://127.0.0.1:5184/space-inversion/worlds/ 。固定摄影、固定观察方向的内层、翻转、外层对照及约 107 秒真实网页录像：http://127.0.0.1:5184/artifacts/spaces/inversion/volume-inversion/index.html 。原画框版本截图与实录继续位于 artifacts/spaces/inversion/ordered-inversion；改前源码保存在 artifacts/spaces/inversion/volume-inversion/source-baseline/src。

第一个单元内的圆和银色旋转曲面使用真实几何，在主场景中接受深度检验与光照，前景骨架可以遮挡它们。圆管的全部顶点、暖白角点的球体顶点、曲面与两根边界的顶点均使用同一投影函数；外部图形无画框或门户纹理。欧拉恒等式采用随源点移动的无框悬浮注记。原有独立阅读场景仍用于约 80% 的阅读视窗。

银色曲面是有限螺旋面的一条径向带：径向线段按复数角度旋转，第三方向的高度与角度成正比。它与圆组成欧拉旋转关系的立体景象，并未把单位圆本身改成三维球。圆上的一个点继续沿原有共享角度缓慢运动，无新增随机相位或外部粒子。

## 同一源图形的投影放大

图形固定在源单元 w=-1 的三个空间坐标范围内。图形顶点和骨架采用相同 XW 旋转与 lens=1.9 的中央投影。端点 θ=0 与 θ=π 的投影尺度分别为 16×1.9/2.9 和 16×1.9/0.9，比例为 2.9/0.9≈3.2222。源图形的四维尺寸和点身份保持不变，增大的是三维投影；没有另外加入人为缩放动画。

中间角度采用逐点投影，形体会变形而不只是均匀缩放。当 θ≈2.12506 弧度时，该源立方单元的三维投影短暂退化为切片。接近这一角度时曲面淡出，保留边界与圆，避免重合曲面的深度闪烁；随后恢复立体。倒角骨架、材质、法线、灯光、图形拾取和跨单元连接仍是普通三维渲染。

## 实际检查

`npm run test:volume-space` 对圆管 2313 个源顶点与曲面 2509 个源顶点采样 722 个角度，其中包括精确退化角。所有点位于源方体内，输入几何保持不变，投影有限，最小投影分母约 0.673585；缓冲投影与结构投影的最大浮点差约 9.54×10⁻⁷。端点每个顶点到单元中心的距离比均为约 3.2222。原有 `npm run test:ordered-space` 的固定连接、中央通路、单事件和 30 分钟 CPU 调度检查也通过。

真实 Edge 155.0.4283.45 的浏览器检查固定摄影和观察方向，运行完整 44 秒事件。两个体积图形的几何包络半径比均为约 3.2222；圆的保守屏幕包络宽度变为约 3.326 倍、高度变为约 3.724 倍，摄影位置与 yaw 保持相同。包络是源形体边界的保守投影，不是逐像素图像分割；大小变化还受到普通三维透视影响。

同一检查实际移动鼠标寻找露出的圆弧，再点击真实圆的网格，确认打开单位圆阅读。对着骨架的点仍被遮挡，文字标签不覆盖图形。门的入场、阅读 80.1% 面积和 0.021 单位/秒非零慢行、欧拉城市与关系故事、六次阅读、单一翻转单元、定格像素、失焦停止、减少动态的手动切换及三个桌面尺寸通过。六次阅读前后预热几何资源同为 80、纹理资源同为 20，页面异常和控制台错误为空。
