图形、纸页、实际点击范围和位置均使用对应源投影。原旧版 XW 中为正面观看设计的渐隐及文字镜像，不应用到本版水平 YW 平面：本版保留真实投影与深度遮挡，不在旧角度人为消失。共享组件新增可选参数，旧入口使用原默认参数。
