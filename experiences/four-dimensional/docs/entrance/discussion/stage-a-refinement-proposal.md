# Mathverse 阶段 A 精修提案：白色阈限与折叠建筑

日期：2026-10-09。状态：设计讨论稿，尚未修改当前运行的主页。

用户已经确认入口采用极简雕塑感。内部空间的具体抽象程度仍在讨论。本稿中的比例、时间和密度都是建议值。

## 1. 本次修改的核心

把体验组织为“安静的小门 → 大尺度空间显现 → 空间关系缓慢改变”。门外强调高亮白色、细长比例和精细实体；门内通过结构投影、不同朝向和嵌套关系建立维度感。

当前空间的档案室感主要来自成排书架、规律水平层板、统一朝向、连续中轴和单一消失点。本次会重构这一组织方式。保留独立的前进路径、自由环顾与少色基调。

## 2. 门前构图与白色

- 1920×1080 下，当前门高约占画面 46%；建议新门高占 26%–30%，先以 28% 为基准。靠拉远初始机位获得小门与大空间的关系，保留穿越时的人体尺度。
- 门居中，视觉重心略低于画面中心。门前文案及操作提示进一步收敛，避免分散注意力。
- 当前背景已经是屏幕纯白。更亮、更有质感的感受通过曝光关系、柔光、材质微差和阴影层次实现。
- 大面积背景维持近白；靠近门的地面带非常轻的冷灰或暖灰渐变。远处墙面与地面的边界消隐。
- 门体使用明亮的哑光石膏或细腻陶瓷质地。只让凹槽、边缘、门缝和接触处承担细小暗部，避免门整体呈灰褐色。
- 材质颗粒只在近距离可察觉，不在画面上覆盖明显噪点。门脚保留柔软接触阴影。

## 3. 极简雕塑拱门

- 采用细长半圆拱，顶部与直立侧边连续连接；实体门板、门框和门洞共享同一条拱形轮廓。
- 门框有真实厚度，边缘加微小倒角，并设置两至三层浅凹槽。细节通过光影显现。
- 门板比当前更明亮，正面保持安静。把手采用短小的金属杆或嵌入式握槽；选择以完整构图为准。
- 开门后能够看见门框内侧、门板厚度、铰链侧和门缝光线变化。
- 门洞遮挡使用真正的拱形几何。进入镜头轨迹重新校准，确保不会碰到门板或拱顶。

## 4. 门内：实体建筑的维度折叠

### 4.1 静止时也成立的空间

重建书架布局，减少水平层板和类似书脊的细条。使用大尺度框架、薄片、嵌套单元和跨度不同的连接结构。相邻单元可有不同朝向，画面包含偏置的消失点与多方向纵深。

结构疏密分区，有大块黑色空域，局部边缘与薄片受到光照。远处保留可追踪的结构，避免所有细节被浓雾吞没。保留实体厚度，关闭后期辉光后仍能辨认体积。

### 4.2 让维度成为变化机制

选一组大型结构作为四维投影主体：顶点包含 x、y、z、w 坐标，缓慢进行 x–w、z–w 平面旋转，再投影到三维进行绘制。

用户看到的效果是：框架的相邻关系、投影尺度和嵌套位置缓慢变化；某些外层结构逐渐进入内层，原本侧向的连接转入纵深。控制形态范围，保持连续性，避免变成任意扭动。

结构变化与相机前进独立。拖拽只改变观察朝向，世界的折叠继续发生。建议完整形态周期为 60–100 秒，初版先使用 80 秒，再根据动态预览调整。

主要折叠发生在中远景，近景保留稳定参照与安全穿越带。不要旋转整台摄像机来替代空间变化。

### 4.3 第一次揭示的标志性画面

开门后首先看见一个远超门体尺度的深色空域，一组巨大框架横贯画面。偏侧结构具有另一组延伸方向，中心留出空隙。

进入并前进数秒后，远处一组结构缓慢嵌入另一组结构，跨接薄片逐步换向。一个更小、不同尺度的拱形轮廓可以在深处再次出现，呼应入口，形成空间记忆。

先把这一幕做成可运行、可环顾的样板，再沿路线扩展。暂时减少现有装饰性几何占位，让空间结构本身承担主题表达。

## 5. 光与材质

门外采用高亮白色与柔软阴影。门内使用深黑、石墨灰、银白和极少的暖白，不增加额外主色。

光集中在断开的结构边缘、交叠处和少量缝隙，照出厚度与方向。允许局部强烈的明暗对比，保留大片安静的暗部。辉光在几何和照明成立后小量加入。

光的变化依附于结构的折叠；大幅闪烁和高速粒子不纳入这一版。交互按钮进一步降低存在感，但仍保持可找到、可操作。

## 6. 实施顺序

1. 入口样板：拱门几何、拉远机位、白场与材质。交付同一桌面尺寸下的新旧构图对比及开门近景。
2. 内部样板：暂停位移，重建首次揭示画面；检查前、侧、上方与后方的结构组织。先验证静态构图和实体层次。
3. 维度变化：接入四维结构投影与缓慢折叠；设置空间安全带、投影距离与形态范围。录制固定视角和持续前进两种片段。
4. 连续体验：重新衔接开门、穿越、前进和转头；控制白场到暗场的适应节奏；完成浏览器检查和构建。

这轮将视觉语言的核心提前到 A 精修。阶段 B 继续专注弹性扭头与入场手感；阶段 C 接入内容和阅读减速；阶段 D 对已确立的视觉进行最终材质和光照打磨；阶段 E 做长时间与性能验收。

## 7. 工程路线

复用 D:\Mathverse 的 React、Three.js 和 React Three Fiber，无需额外下载软件。

- 门使用轮廓曲线与挤出几何，门框、门板和洞口由统一参数生成。
- 空间拆分为稳定的近景参照、四维投影的中远景主体和轻量远景结构。
- 四维计算与渲染分离，投影后的数据写入复用的几何或实例缓冲；控制单元数量，避免每帧重建对象。
- 相机仍由单一控制器管理；结构变化由独立的空间时间参数管理。
- 重要参数集中配置：门的屏幕占比、拱形比例、白场曝光关系、结构层级、第四轴角度范围、折叠周期和可见距离。
- 先制作局部高质量场景并在目标电脑测量，再决定延伸长度、细节密度和后期质量。

## 8. 精修验收

- 门占比明显减小，白场明亮但门轮廓与细部可读。
- 拱门完整参与开合与穿越，不存在矩形洞口露边或镜头碰撞。
- 进入后第一眼能看到多方向、多个层级的空间，不再以水平书架层板作为主要形态。
- 相机停止时，结构自身依然能够呈现缓慢的维度变化。
- 拖拽能从另一个角度验证结构的厚度、嵌套与变化，前进路线保持独立。
- 提供至少 20 秒连续片段；检查快速拖拽、回望、暂停和失焦恢复。
- 实测目标电脑的帧时间；未测的性能、长时间运行和资源增长仍标为未测。
