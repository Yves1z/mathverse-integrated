# 阶段 B：入场与完整镜头手感

完成日期：2026-10-09。可交互预览：http://127.0.0.1:5184/ 。连续演示：http://127.0.0.1:5184/artifacts/interaction/stage-b/index.html 。

## 已实现体验

- 保留阶段 A 精修的明亮白场、小型雕塑拱门与四维投影结构。点击后，门向内部打开，内部结构经门洞逐渐显露；相机沿同一条路径穿过真实门洞，连续进入空间。
- 入场位置、速度与加速度平滑衔接。入场末端速度为 0.35 场景单位/秒，与持续探索速度相同。
- 拖拽只控制观察方向，前进路线始终独立。转头采用阻尼弹簧，普通手势收尾约 0.31–0.33 秒，只有很小的过冲。
- 水平转头无角度截断，可连续经过 180° 回望。松手保留方向；“看向前方”沿最短角度缓慢返回。
- 上下观察限制在 ±55°；外侧 7° 逐渐增加阻力，反向拖动立即离开边界。镜头无滚转。
- 小于 6 CSS px 的移动不触发拖拽；Pointer Capture 保证释放、取消、失焦都能结束手势。
- 暂停旅程时相机缓慢刹停，背景继续变化；继续旅程时缓慢加速。“定格空间”单独控制结构的时间。
- 网页失焦或隐藏时挂起路径和结构时钟，返回后不补跑离开的时间。入场中途失焦也不会改变最终观察方向。
- 修复旧门框的门洞轮廓超出外轮廓导致的遮挡；通过真实三角几何的射线检查确认眼睛高度处通道畅通。

## 可调参数

主要参数位于 `src/mathverse/config/motion.ts`。空间配色、密度与第四轴周期仍位于 `src/mathverse/config/visual.ts`。

| 参数 | 当前值 | 影响 |
|---|---|---|
| 初始机位 | z = 9.6，眼高 1.55 | 保持门小而留白充足 |
| 入场启动等待 | 0.85 秒 | 先看到门的运动，再开始深入 |
| 入场镜头 | 6.0 秒 | 点击后总入场时长 6.85 秒 |
| 开门 | 2.55 秒，99.9° | 相机到达门洞前门板已让开 |
| 探索速度 | 0.35 单位/秒 | 持续缓慢深入 |
| 转头自然频率 | 3 Hz | 响应与收尾速度 |
| 转头阻尼比 | 0.94 | 克制的弹性 |
| 上下角度 | ±55°，外侧 7° 柔软区 | 保持方向感 |
| 最大角速度 | 7.5 rad/s | 限制极端快速输入 |
| 速度变化半衰期 | 0.12 秒 | 暂停、恢复与后续阅读减速 |
| 最大帧时间 | 0.05 秒 | 防止单次掉帧造成跳跃 |
| 弹簧子步 | 不超过 1/120 秒 | 提高不同刷新率下的一致性 |

`MotionKernel.ts` 负责纯运动计算；`CameraDirector.tsx` 是唯一写入相机位置和朝向的组件。背景使用同一份有效帧时间，避免前景停住而背景补跑。`speedScale` 为下一阶段阅读减速保留接口；数学阅读交互尚未接入。

## 实际验证

生产构建与全部阶段 B 检查通过。浏览器使用原有 Edge 154.0.4258.62；功能检查覆盖 1920×1080 和 1280×720，录屏为 1600×900。

同一段 20 秒运动序列包含入场、转头、暂停、恢复和返回前方，模拟结果如下：

| 模拟刷新率 | 探索累计距离 | 普通转头进入 1% 误差范围 | 入场末端速度 |
|---|---|---|---|
| 30 Hz | 3.902500 | 0.333 秒 | 0.350000 |
| 60 Hz | 3.902500 | 0.317 秒 | 0.350000 |
| 120 Hz | 3.902500 | 0.308 秒 | 0.350000 |

三组累计距离最大差约 5.1×10⁻¹⁴ 单位。30/60/120 Hz 数据是运动算法模拟，不是电脑实际 GPU 帧率。

浏览器检查确认：连续入场与前进、柔和暂停和恢复、独立结构时钟、6 px 拖拽阈值、松手不归正、软边界反向响应、跨越 180°、最短方向返回、失焦取消拖拽、恢复不跳、无镜头滚转。穿门过程相机距门板的保守最小间距约 0.573 单位；穿越门平面时门已打开超过 85°。捕获的页面异常与控制台错误均为零。

连续录像文件为 `artifacts/interaction/stage-b/stage-b-demo.webm`，媒体实际时长 **27.04 秒**。已在网页播放器中验证媒体就绪、1600×900 解码及播放；不是静态截图拼接。播放页位于 `artifacts/interaction/stage-b/index.html`，通过开发服务器访问。

详细数据：`artifacts/interaction/stage-b/motion-verification.json`、`artifacts/interaction/stage-b/browser-verification.json`。代表画面：`entrance.png`、`door-opening.png`、`interior-forward.png`、`interior-side.png`、`interior-back.png` 和 `desktop-1280.png`。
