# 阶段 C：数学节点与完整阅读循环

完成日期：2026-10-09。可交互预览：http://127.0.0.1:5184/ 。画面与连续演示：http://127.0.0.1:5184/artifacts/worlds/stage-c/index.html 。

## 当前可以体验的内容

空间中加入六个固定节点：欧拉恒等式、高斯积分、单位圆、莫比乌斯带、欧拉人物占位与复数旋转关联。公式有独立的空间朝向；图形使用实时三维几何。没有用生成肖像冒充历史资料。

第一组公式与单位圆在入场后可见，后续节点沿路径分布。距离与画面边界采用不同的进入、退出阈值，降低边界闪烁；每个视野最多强调三个节点。停留 250 ms 后，悬停目标会使探索速度轻微下降到 75%。结构可以遮挡数学对象，鼠标拾取比较数学对象与实体阻挡面的距离；扩大拾取范围不会绕过遮挡。

点击节点后保存观察方向，背景平滑减速到探索速度的 6%，对象转入稳定的独立观察层。阅读期间背景持续前进，正文可以选择和滚动，主场景拖拽停用。单位圆与复数旋转可调节角度；莫比乌斯带可改变展示方向。

关闭按钮或 Esc 退出阅读。镜头恢复进入阅读前的观察方向，从当前路径位置继续，速度在约 1.8 秒内渐进恢复。若进入前手动暂停，则退出后恢复这个暂停偏好；阅读本身保持非零缓慢位移。即使从索引打开已经走过的节点，也不会退回它原来的位置。

右上“数学索引”提供全部六个节点的 HTML 入口，支持键盘操作。阅读面板与索引都有焦点管理；关闭后返回原入口或索引按钮。切换关联内容时，正文回到开头，键盘焦点移到新标题。

主摄像头仍只有 `CameraDirector.tsx` 一个写入者。观察层使用同一 renderer 的独立 scene 和静态摄像头：先绘制世界，再清理深度并绘制观察层。观察几何保留深度测试，曲面的前后遮挡成立。没有另开一套 Canvas 或重复渲染循环。

世界节点与观察副本共用几何和公式纹理；材质由各自实例管理。关闭阅读不会释放世界仍需要的共享资产。公式的空间纹理由 Canvas 排版生成，HTML 阅读中的主公式和行内数学使用 KaTeX。

## 实际检查结果

生产构建、阶段 B 运动逻辑与镜头浏览器回归均通过。阶段 C 使用现有 Edge 154.0.4258.62，检查视口为 1600×900 和 1280×720；未新增软件。

运动与几何逻辑检查覆盖：六个稳定 ID 和关联完整性、6% 非零速度、30/60/120 Hz 下三分钟阅读模拟、退出方向恢复、旧节点不回退位置、聚焦中快速关闭、20 次循环、悬停计时、隐藏时钟、实例化实体遮挡、不可见薄片不误挡，以及莫比乌斯半扭转的几何接缝。

同一段阅读序列，三种刷新率下三分钟阅读的累计位移均为 **3.78 单位**。包含进出过渡的整个序列，最大距离差约 0.0042 单位，约占累计距离 0.09%。这是运动算法模拟，不是 GPU 帧率测量。

真实浏览器检查确认：

- 拖动超过阈值后再回到起点，也不会误打开对象；小幅点击可打开真实场景节点。
- 阅读时拖动背景不会改变观察方向，正文可选择、面板可独立滚动。
- 单位圆角度控制和公式—图形—关联阅读链可用。
- Esc、关闭按钮、索引键盘操作、焦点限制和返回入口正常。
- 20 次交替的正常、快速开关后，纹理计数维持 7；几何对比采样为 29 → 30。长读结束时为 28。未观察到这组检查中持续累积的资源数量。
- 连续阅读莫比乌斯带 **180.097 秒墙钟时间**，有效运动时钟推进约 180.025 秒；背景前进 **3.78034 单位**，速度稳定为 **0.021**。观察层中心坐标维持 **(492, 422.986)**，没有因路径前进滑出画面。
- 阅读期间失焦会暂停路径、结构与阅读时钟，恢复后不补跑。长读后退出可继续探索。
- 最后的关联阅读滚动归零、标题焦点与公式排版另行复查通过。

捕获的页面异常和控制台错误为零。详细报告位于 `artifacts/worlds/stage-c/logic-verification.json`、`browser-verification.json`、`reading-ui-verification.json` 和 `video-verification.json`。连续录像 `stage-c-demo.webm` 为 1600×900，媒体时长约 **32.24 秒**，覆盖入场、发现、公式阅读、关联图形、角度调节、索引、莫比乌斯带和退出。

## 数学资料核对
