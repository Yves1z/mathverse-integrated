## 视觉与运动

光线采用冷灰石墨与少量暖色余光。主体框架降低自发光，采用粗糙度较高的石墨金属；薄层使用细微的拉丝变化和掠射轮廓。小尺度拉丝随屏幕导数衰减，以减少远景细节的闪烁。窗口内侧提高材质明暗差异，边缘窄缝、连接光点和数学标记保留暖色亮度。

门外继续保持明亮白场。过门时，环境补光与最终曝光处理随真实镜头位置平滑衔接。门内采用方向主光、弱半球补光和有限的暖色侧光；主光仅作缓慢、低幅度变化，镜头不加入晃动或滚转。

光幕是具有真实世界位置、深度测试和距离衰减的程序化薄片，表现结构之间透出的空气感。它属于艺术近似，不是物理体积散射模拟。光幕按世界段落固定，不随摄像头整片搬动；远处渐隐，分段更新保留重合段的位置和相位。

粒子分为三层，固定资产预算为 **2496** 个点：

- 1440 个空间微尘，保留世界位置、不同深度、稳定段落随机种子，以及缓慢漂移与受光差异。
- 96 个连接光点，沿连接通道按弧长采样，余弦时间曲线使端点缓慢转向。
- 六个内部世界各 160 个粒子：单位圆与恒等式的相位轨迹、复指数螺旋、高斯曲面、莫比乌斯带的连续边界、人物窗口中的少量微尘。预算指固定创建的点数，探索时内部世界仍轮换绘制，并非每帧重绘全部窗口。

圆与螺旋仍共享同一个角度参数；螺旋粒子在可见区两端渐隐后循环，主要标记点的深度保持连续。莫比乌斯边界使用 4π 周期。新增粒子不参与内容拾取，保持正常深度测试，不覆盖正文。结构定格、失焦与页面隐藏沿用共同的动画时钟。

## 渲染流程

最终合成仍由 `ObservationLayer` 统一执行：

1. 轮换更新可见窗口的内部 render target。
2. 主世界与正在展开的阅读世界统一绘制到 HDR 缓冲；阅读只裁剪内部区域，保留外围世界。
3. 仅对越过亮度阈值的区域生成多尺度 Bloom。
4. 执行曝光、ACES 色调映射、sRGB 输出、轻微边缘衰减与固定的细颗粒。
5. 最后进行 FXAA，改善细线与小粒子的边缘。

白色门前不启用 Bloom。正文、按钮与公式说明保持原生 HTML 清晰度，不经过场景后期。未增加景深、运动模糊、色散、全场动态阴影或频闪。

主要可调值见 `src/mathverse/config/atmosphere.ts`：Bloom 强度 0.30、半径 0.48、线性亮度阈值 1.12，分辨率系数 0.70，曝光 0.96，固定颗粒幅度 0.0025。主 HDR 缓冲采用 2 样本 MSAA，再结合最终 FXAA。DPR 上限仍为 1.5。

高斯曲面用疏朗坐标网格替代密集三角线框，网格与曲面保持小间隔，以减少深度竞争。人物纸页仍是艺术构图，本轮光影精修不把它描述为原始历史手稿。

## 实际验证

本轮使用现有 Edge 154.0.4258.62，TypeScript 检查与生产构建通过。生产主包约 1.48 MB，仍有拆包提示；拆包留在集成与交付阶段。

- 六个数学世界正常显示，原生鼠标拾取、拖拽与点击区分、参数操作、关联切换、正文选择与滚动、Esc 恢复和键盘焦点检查通过。
- **20 次正常／快速开关**：几何数量 129 → 129，纹理数量 26 → 26，本组没有观察到持续累积。
- **真实连续阅读 180.095 秒**：有效时钟约 179.9915 秒，路径前进 3.77960 单位，速度为 0.021，即探索速度的 6%；对象屏幕位置、正文与窗口构图保持稳定。
- 定格结构时，光线、粒子与连接时钟停留，路径继续前进；失焦暂停与恢复检查通过。
- 桌面 1280×720、1440×900、1920×1080，模拟设备像素比 2、实际渲染上限 1.5：HDR 缓冲尺寸正确，阅读面积约 80.1%，外围结构可见。另通过普通像素比的 1600×900、1280×720 交互回归。
- 关闭 Bloom 后真实渲染并保存画面，保留结构的明暗、实体厚度与纵深；没有使用后期效果替代空间主体。
- 正常速度实际前进跨过一个粒子段落：记录窗口 76.072 秒，采样终点路径距离 26.83366；段落 -3 → -2，固定粒子和光幕数量保持不变。几何 129 → 130，纹理 26 → 26。本组只覆盖一次段落交接，不代表十分钟资源验收完成。
- 连续演示媒体实际时长 **43.36 秒、1600×900**，浏览器原生播放器已确认无错误并实际播放。包含白场、门缝、环顾、定格、关联阅读、曲面、人物痕迹与返回。
- 本轮页面异常与捕获的控制台错误为零。

检查报告与画面位于 `artifacts/worlds/stage-d-light`：`browser-verification.json`、`light-browser-verification.json`、各状态截图、`stage-d-light-demo.webm` 和演示页。本轮没有将真实交互检查称为 GPU 帧率基准。
