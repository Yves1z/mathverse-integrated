# 数学窗口与空间连接精修

日期：2026-10-09。范围：本轮落实已确认的抽象数学窗口、少量人的痕迹、80%／20%阅读构图，并继续打磨四维投影与连接运动。阶段 C 基础源码保存在 `artifacts/archive/sources/stage-c-source/src`。

实时主页：http://127.0.0.1:5184/ 。连续演示与画面页：http://127.0.0.1:5184/artifacts/worlds/stage-d-windows/index.html 。

## 已实现的体验

六个节点升级为有厚度、内侧斜面和遮挡的窗口。每扇窗口连接独立的实时三维 scene，通过观察位置驱动有限幅度的内部视差；探索时将内部世界绘制到共享 renderer 的固定 render target，再呈现在实体开口中。窗口没有依赖图片或视频作为场景背景。

单位圆、复指数与欧拉恒等式共用一个角度。单位圆上的点、复指数螺旋上的点和欧拉窗口中的点由同一状态驱动；阅读中调整角度，三个内部世界同步响应。切换关联内容保留当前角度。欧拉窗口中的等式在半周附近渐渐显露。螺旋以当前相位为中心连续展开，角度跨越循环边界时保持深度连续。

人物窗口以少量纸页、名字和符号呈现人的痕迹；纸页明确属于艺术构图，未冒充原始手稿，也没有生成历史肖像。原始文献的核实入口仍在阅读说明中。高斯窗口显示径向衰减曲面，莫比乌斯窗口保留可调展示方向的真实曲面。

空间主体与连接框架共用 XW、ZW 两个四维旋转和平滑的四维到三维透视投影。旋转保持四维范数；时间连续，分段结构使用局部相位差。调低薄层密度，放慢折叠，周期性的相位收拢使局部结构逐渐出现更一致的关系。主路径的安全淡出仍然有效。

首组三扇窗口之间增加 19 组横截框与连续纵向连接。少量暖光沿结构往返传播：轨迹按弧长采样，余弦时间曲线使端点减速、转向连续。窗口自身只作约 1.4°俯仰、3.2°偏转的轻微缓慢变化；主镜头继续沿原路径前进，拖拽仍然只控制有阻尼的转头。

阅读从所选开口的投影范围展开至中央窗口，按约 90%视口宽、89%视口高构图，面积约 **80.1%**。内部世界、公式、说明和控件在窗口内；外围保留真实世界的结构与运动。最终合成使用 viewport/scissor 限定内部绘制范围，保留正常的内部深度关系，外围没有全屏暗幕。退出平滑收拢，保持当前路径位置和既有方向、速度恢复规则。

## 实现与参数

| 模块 | 职责 |
|---|---|
| `windows/windowMotion.ts` | 共同角度、四维旋转与投影、相位收拢、窗口矩形与插值 |
| `windows/WindowAssets.ts` | 六个固定内部 scene、render target 和共用几何 |
| `windows/WindowWorld.tsx` | 圆、相位螺旋、径向曲面、莫比乌斯带、抽象纸页 |
| `windows/PortalWindow.tsx` | 开口、内侧斜面、边框、实体厚度与公式刻记 |
| `windows/WindowConnections.tsx` | 连续连接框、共享运动与暖光传播 |
| `reading/ObservationLayer.tsx` | 唯一最终合成器；内部窗口展开与外围保留 |
| `content/MathField.tsx` | 窗口的发现、布局、轻微姿态变化和投影入口 |

折叠基础周期为 112 秒，较慢分量跨两个周期；连接暖光的完整往返为 68 秒。阅读速度仍为 0.021 场景单位/秒，即探索速度 0.35 的 6%。主要四维旋转基底每组框架计算一次，顶点复用；六个 render target 固定复用，探索时轮换更新可见窗口，阅读世界每帧直接绘制。关闭阅读不会创建或销毁整套内部世界。

## 实际验证

- TypeScript 与生产构建通过。既有 30／60／120 Hz 镜头、阅读与遮挡逻辑通过。
- 四维检查覆盖三组主要尺寸的全部顶点符号组合及 224 秒时间范围：范数保持、投影有限，测试中的最小透视分母约 2.59；120 Hz 单步最大投影位移约 0.0041 单位。模拟不代表实际 GPU 帧率。
- 真实浏览器确认三扇窗口的实际点坐标与共同角度一致；关联切换保留参数，螺旋循环没有深度跳变。
- 定格结构时路径仍前进；阅读世界构图保持稳定，外围时钟与路径继续；退出、文本选择、正文滚动、原生鼠标拾取及键盘返回通过。
- 20 次正常／快速开关后，纹理计数保持 13；几何采样为 111 → 112，长读结束为 111。本组检查没有观察到持续累积。
- 真实连续阅读 **180.083 秒**，有效运动时钟约 179.987 秒，路径前进 **3.77954 单位**，速度为 **0.021**。这组长读验证完成后，另对旋转轨迹连续性与最终窗口构图作定向复查。
- 桌面 1280×720、1440×900、1920×1080、2560×1440 的实际 HTML 窗口面积约 80.1%，阅读面板均在窗口范围内。页面异常与捕获的控制台错误为零。
- 连续演示媒体为 **39.24 秒、1600×900、VP9**，覆盖入场、环顾、结构定格、关联窗口、角度控制、人物痕迹与返回。

记录位于 `artifacts/worlds/stage-d-windows`：`window-logic-verification.json`、`window-browser-verification.json`、`browser-verification.json`、`logic-verification.json`、截图与录像。浏览器为现有 Edge 154.0.4258.62。

## 范围与后续

本轮是窗口与空间连接的运动精修。精确的单一观察位置轨迹拼接、原始历史文献图像、最终 Bloom/整体光影以及完整 GPU 与长时资源验收仍属后续工作；当前相位收拢与关联参数已经运行，不将它等同于精确视角拼接完成。构建仍提示主包约 1.45 MB，拆包与正式工程集成留在交付阶段。

本轮没有新增软件或依赖；源码、开发缓存、截图和录像保存在 D 盘。正式 mathweb 业务工程未修改。可运行 `npm run test:windows` 与 `npm run test:windows-browser` 复查本轮新增逻辑和交互；运行现有阶段 C 浏览器回归时，可将 `MATHVERSE_TEST_OUTPUT` 指向本轮目录以保留历史记录。
