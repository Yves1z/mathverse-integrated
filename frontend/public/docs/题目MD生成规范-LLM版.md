# 试卷 PDF → 题目 MD 生成规范（LLM 专用）

版本 1.4。编写日期：2026-09-22。依据平台《题目上传规则》1.4 与后台「题目管理 → 批量导入」的实际校验规则编写；标点、选项排版、小问编号、填空空位等书写体例参照项目内《如何制作一份高考数学原版试卷？》整理的高考原卷惯例：中文语句用中文标点、句末用全角句点 `．`，数学公式内一律英文半角；其中选项排版由平台按宽度自动处理。`title` 必须是「试卷名称＋题号」（照抄 `id`），不是知识点。

**使用方式**：把这份规范连同**一份试卷 PDF** 交给模型；模型为每道题输出一个 `.md` 文件（需要配图的题目另外输出图片文件）。生成结果由管理员在后台批量导入，导入后只是草稿，仍需人工审核，审核通过才发布。

**生成者必须在开始前读完第 0、1 节；第 1 节是最高优先级规则，与其它描述冲突时以第 1 节为准。**

---

## 0. 交付物

输入：一份试卷 PDF（可能含卷首说明、全部试题、卷末参考答案与解析）。

输出：一个以试卷命名的文件夹，形如

```text
2026新高考Ⅱ卷/
  2026新高考Ⅱ卷T1.md
  2026新高考Ⅱ卷T17.md
  T17-题图.png
```

- 每道题一个 `.md` 文件，UTF-8 编码；Windows 或 Unix 换行均可。
- 需要配图的题目，把图片文件放在同一文件夹，文件名与 MD 中的引用完全一致。
- 含 （1）（2）（3）多个小问的解答题算**一道题**，只生成一个文件、用一个题号。
- 平台题号（如 `GC000123`）由系统在发布时生成，**不要在 MD 里编造或填写**。
- 不需要输出汇总表、说明文档、HTML 报告或做题笔记。

## 1. 最高优先级规则：能转写的必须转写，配图只给“没有图就不成立”的题

### 1.1 默认动作：把题目的全部内容转写成文字与 LaTeX

题干、选项、条件、括号、单位、小字说明、数据、符号、公式，**一律逐字转写**为文字与 LaTeX。转写要忠实于原卷，不得改写、简化、省略，不得猜测缺失内容。

### 1.2 只有图形本身承载解题信息时，才截图作为配图

判断方法（逐题自问一次）：**把这道题的图形删掉，题干信息还完整吗？**

- 还完整、仍能作答 → **不截图**，全部转写。
- 不完整、无法作答 → **截图**，并且只截这个图形。

典型需要配图的题：

- 立体几何：三视图、直观图、展开图、截面图、外接球 / 内切球示意图；
- 平面几何图形：三角形、圆、四边形及其标注；
- 函数图像、导数草图、坐标系中的点 / 直线 / 曲线；
- 统计图表：频率分布直方图、散点图、茎叶图、折线图、扇形图；
- 程序框图 / 流程图；
- 概率的树状图、几何概型的区域图；
- 带空白的待作图图形。

典型**不需要**配图的题（必须全部转写）：

- 集合、复数、数列、计数原理、概率的文字题；
- 只由公式和文字构成的题；
- 题干很长但全是文字的题（长 ≠ 要截图）；
- 选项 A/B/C/D 本身；
- 数据表、参考数据、参考公式、临界值表——这些是文字内容，转写成文字行，不要截图。

### 1.3 严格禁止的写法

以下都是错误做法，禁止生成：

- 用「截图」「见图」「如图（此处为图片）」「图片略」「图形略」「略」等占位文字，替代任何可以转写的内容；
- 因为「公式太复杂」就写「（公式见原卷）」而不转写；
- 把整页试卷、整道题的题干区域当成「题目图片」截图；
- 把题干文字、选项、公式截图当作内容贴进来；
- 抄写、转述 PDF 里没有的文字（包括自行补写的过渡句）。

**每道题都必须先有完整的文字与 LaTeX 转写，配图只是转写之上的补充。**

### 1.4 图片文件名、截图范围与引用位置

- 命名：`T<原题号>-题图.png`；同一题多张图用 `T<原题号>-题图1.png`、`T<原题号>-题图2.png`；出现在答案 / 解析中的图用 `T<原题号>-解析图.png`。
- 文件名只用中英文、数字和连字符 `-`，不要用空格或 `/ \ : * ? " < > |`；同一文件夹内不能重名。
- 只截图形本身：不要包含题号、题干文字、相邻题目或页面边距。
- 分辨率以图中标注的字母、数字清晰可辨为准；不要拉伸变形，不要过度压缩变模糊；单张图片不超过 10MB。
- 引用写在正文中图形出现的位置，用 Markdown 图片语法：`![题图](T17-题图.png)`。解析图写在 `solution:` 段内。
- 不需要配图的题目**不要写任何图片引用**；结尾写 `img:0` 即可。
- `img:0`（或 `img:{...}`）只能写在**文件最后一行**。它同样是一个分段标记，写在正文中间会提前结束当前段，导致后面的内容丢失。

### 1.5 如果运行环境无法输出图片文件

仍然必须完整转写全部文字与公式，然后在 `content:` 段**全部文字之后**另起一行写：

```text
（本题原卷含图，配图待补：<一句话说明图形内容>）
```

此时不要写图片引用（因为文件不存在），也不要写 `img:{...}`。这是唯一允许出现的「配图待补」写法，且**绝不能替代题干文字**。若你的环境能够裁剪 / 导出图片（多数情况可以），就必须正常产出图片文件，不要走这条兜底。

## 2. 元数据块

文件结构固定为：元数据块 → `content:` 段 → `answer:` 段 → `solution:` 段 →（可选）`img:` 行。

```markdown
---
id:2026新高考Ⅱ卷T17
title:2026新高考Ⅱ卷T17
year:2026
source:新高考Ⅱ卷
source_category:G
question_type:解答题
number:T17
difficulty:D5
tags:立体几何
curriculum:PEP-A-2019
chapters:A23,A31
---
content:
……（题干与选项；需要配图时在图出现的位置写图片引用）
answer:
……（原卷给出的答案；原卷没有就留空）
solution:
……（原卷给出的解析；原卷没有就留空）
img:0
```

### 2.1 语法硬规则

1. 文件**第一行必须是 `---`**，前面不能有任何内容。
2. 元数据结束时必须有第二行 `---`，不能省略。
3. 块内每行一个字段，写法是 `字段名:值`，一行写完；中文冒号 `：` 也能识别，但建议统一使用英文冒号。
4. 值**不加引号**，不换行，不写 YAML 列表、JSON 数组或缩进。
5. 字段名只能是小写英文、数字、下划线。**写错字段名不会报错，但会被静默忽略**，所以必须逐字使用下表字段名。
6. 多个值用英文逗号分隔（中文逗号也可识别）。

### 2.2 字段表

| 字段 | 要求 | 写法 |
|---|---|---|
| `id` | 必填 | 原始资料标识，建议「年份＋来源＋原卷题号」，如 `2026新高考Ⅱ卷T17`；同一份试卷内唯一。不要填平台题号。 |
| `title` | 必填 | **试卷名称＋题号**，即照抄 `id` 的值，如 `2026新高考Ⅱ卷T17`；用于审核队列与题目列表识别。**不要写成知识点、题型或内容概括**（如「等差数列的通项」「平面向量基本定理」「曲线在一点处的切线方程」）。不填时系统用 `id` 顶替，效果相同。 |
| `year` | 必填 | 四位年份，如 `2026`；课本、自编或年份不明时写 `0000`。 |
| `source` | 必填 | 规范来源名，见 §5.4；**不要自创名称**，自创名称会在发布时被拦截。 |
| `source_category` | 必填 | `G` 高考 ／ `E` 其他正式考试 ／ `T` 课本教材 ／ `N` 其他（模拟、原创、来源不明）。 |
| `question_type` | 必填 | `单选题`、`多选题`、`填空题`、`解答题` 四选一。 |
| `number` | 必填 | 原卷题号，`T17` 或 `17` 均可（系统内部等价）；同一试卷内必须唯一；不要写 `0`。 |
| `difficulty` | 必填 | `D1`～`D7` 之一，见附录 C；不要写 `BLACK`/`WHITE`，不要写「中等」「难」。 |
| `tags` | 必填 | 只能从附录 B 的 10 个大类中逐字选择，可多选，逗号分隔，如 `立体几何` 或 `函数与导数,不等式`。 |
| `curriculum` | 必填 | 固定写 `PEP-A-2019`。 |
| `chapters` | 选填 | 从附录 A 的 18 个代码中选，逗号分隔，如 `A23,A31`；不确定可留空。写附录之外的代码会被导入直接拦截。 |

旧字段（`creator_uid`、`created_at`、`updated_at`、`problem_number`）写不写都不影响结果；不要写密码、令牌等任何敏感信息。

## 3. 三段正文

### 3.1 分段标记

- 三个标记行 `content:`、`answer:`、`solution:` **必须顶格书写**（前面不能有空格、缩进、`-`、`>`）。
- 一段从标记行开始，到下一个分段标记或文件结尾结束，因此正文里不要另起一行以 `content:`、`answer:`、`solution:`、`img:` 开头。
- 不要在正文里用单独一行的 `---` 做分隔线（容易与元数据块混淆）。
- 不要把整段内容包在 ``` 代码块里。
- **禁止 HTML 标签**（会被拦截）。Markdown 的标题、表格、加粗不是平台的完整排版协议，显示效果以平台预览为准，请少用；数据表优先改写成文字行，例如 `x：1，2，3`。
- 标点按 §3.2 的规则写：中文语句用中文标点、句末用全角句点 `．`，数学公式内一律英文半角。
- 字体、字号、页边距、题号、分值、卷头与题型说明、选项排版、打印时的行距缩进，都由平台在阅读与组卷打印时统一安排，转写时不用考虑；**也不要用空格手工对齐、缩进或补空行**，排版一律交给平台。
- 段落之间空行随意。

### 3.2 标点

**这一节最容易出错，务必逐条对照。**

高考原卷的标点分两种语境，转写时不要混用：

- **中文语句部分**：用中文标点——逗号 `，`、分号 `；`、冒号 `：`、问号 `？`、叹号 `！`、括号 `（）`、引号 `“”`；**句末一律用全角句点 `．`**（不是 `。`，更不是英文 `.`）。例：`则 $m$ 的取值范围是______．`
- **数学公式内部**（含行内 `$...$` 与独立公式）：逗号、句点、括号、冒号、分号**一律用英文半角**。试卷里的 `(2,m)`、`(-2,6)`、`f(x)=x^{2}-x`、`a_1,a_2,\cdots,a_8`、`P(X=i)=p_i` 都是这种写法，`A\cap B`、`\dfrac{\pi}{4}` 一类公式内的符号也全是半角。**绝对不要把 `，`、`．`、`（`、`）` 写进公式**，全角标点在公式里会渲染错乱。
- 中文与公式相接处照原卷紧挨着写：`已知集合 $M=\{-2, -1\}$，则 $M\cap N=$（ ）`

常见错误对照：

| 错误写法 | 正确写法 |
|---|---|
| `$(-2，6)$` | `$(-2,6)$` |
| `取值范围是 $m>1$。` | `取值范围是 $m>1$．` |
| `$f（x）$` | `$f(x)$` |
| `$a_1、a_2$` | `$a_1,a_2$` |
| `$x=1$ ，` | `$x=1$，` |

### 3.3 公式

- 行内公式用 `$...$`，独立公式用 `$$...$$` 单独成行。
- 定界符必须成对，机器会校验 `$`/`$$` 未配对并拦截。
- `$...$` 内只放数学内容，中文说明写在公式外。
- 不要用 `\(`、`\[` 等其它定界符，不要用 `\n` 之类的转义。

### 3.4 选项

高考卷的选项有三种排版（一行四选项 / 两行两选项 / 四行一选项），但**转写时不用管排版**：平台在阅读和组卷打印时都会按可用宽度自动排成合适的列数。照原卷提取到什么形式就写什么形式，一行、两行、四行都合法。

必须满足的只有下面两条，它们是平台识别选项的唯一依据：

- 每个选项写成 `A. 内容` 的形式（字母＋半角句点，`A．` 也识别）；**字母前必须是行首或空格**，写在同一行的选项之间用空格隔开（推荐全角空格 `　`）。缺空格会识别失败，阅读和组卷时都排不出选项列。
- 四个选项各自独立成式，例如 `A. $7$　B. $9$　C. $11$　D. $13$`；**不要拼成一个大公式**（如 `$A.7,B.9,C.11,D.13$`）。老题里 `$\text{A．}…\qquad\text{B．}…$` 这种写法平台仍能识别并自动拆分，但新转写一律用上面的写法。

选项内容逐字转写，不带题号、不带「（ ）」；选项内含图时仍按 §1 的规则单独出图。

一行四选项示例：

```text
content:
已知等差数列 $\{a_n\}$ 的首项为 $1$，公差为 $2$，则 $a_5=$（ ）
A. $7$　B. $9$　C. $11$　D. $13$
```

四行一选项示例（照原卷分行写也可以）：

```text
content:
下列函数中，在区间 $(0,+\infty)$ 上单调递增的是（ ）
A. $f(x)=-\dfrac{1}{x}$
B. $f(x)=x^2-2x$
C. $f(x)=2^{-x}$
D. $f(x)=\log_{\frac{1}{2}}x$
```

### 3.5 小问与层级

- 小问编号沿用原卷，高考卷惯例：第一层用中文括号＋阿拉伯数字 `（1）`、`（2）`；小问里再套小问时，第二层用中文括号＋罗马数字 `（i）`、`（ii）`（大写 `（Ⅰ）`、`（Ⅱ）` 也能识别）。
- **每个小问另起一行，编号写在行首**，不要接在题干或上一小问文字后面。平台按行首识别小问，并自动做悬挂缩进、对齐编号；写在行中间不会生效。
- 小问内容自然换行即可，不要手工缩进、对齐或加多余空行。
- 原卷用 `①②`、`1.` 等其它编号形式时照原样转写（平台按普通文字显示），不要自创编号。

### 3.6 填空题的空位

- 作答空位用连续半角下划线表示，推荐 10 个：`__________`，紧跟在 `=` 或提示文字之后。
- 原卷空位后带句点、单位、括号的，一并保留；一句话里有多个空的，按原卷位置逐个写出。
- 不要用 `（ ）`、空格或全角下划线代替填空空位。

```text
content:
设 $f(x)=x^2-2x$，则 $f(1)=$__________．
```

### 3.7 材料段

题干中给出的阅读材料、情境材料，用 `:::material` 包起来，标记各自独立占一行、顶格，且必须成对（机器会校验）：

```text
content:
:::material
某研究小组记录了一组数据……
:::
根据材料回答下列问题．
```

材料段内的行不要以 `#` 开头。

### 3.8 答案与解析

- `answer:` 只写原卷给出的答案：选择题写选项字母（多选题写全部正确选项），填空题写答案文本，解答题写最终结论。
- `solution:` 只转写原卷给出的解析。
- **原卷没有答案或解析时，对应段留空**（平台允许留空，审核阶段处理）。**绝不允许自行解题、补写、猜测或「根据常识补上」。**
- 不得改动题干中的数字、条件、选项、关系符号和结论。

## 4. 目录与文件

- 一张试卷一个文件夹，文件夹名用试卷全称，例如 `2026新高考Ⅱ卷`；文件名建议 `2026新高考Ⅱ卷T17.md`。
- 图片与对应 MD 放在同一文件夹内。
- 卷首的「注意事项」「参考公式」等说明文字不生成题目文件；卷末的「参考答案与解析」按题号拆写到各题的 `answer:` / `solution:` 段，不单独生成文件。
- 容量限制：单个 MD ≤ 2MB，单张图片 ≤ 10MB，单题（MD + 图片）合计 ≤ 12MB。图片过大时先压缩。

## 5. 分类信息怎么判断

### 5.1 题型

四个选项中只有一个正确 → `单选题`；提示「有多项符合题目要求」→ `多选题`；留空作答 → `填空题`；需要写过程、证明或计算步骤 → `解答题`。

### 5.2 tags

从附录 B 的 10 个大类中选，可多选。例如导数与不等式结合的题写 `函数与导数,不等式`；含空间向量的立体几何题只写 `立体几何`（空间向量属于立体几何大类）。

### 5.3 chapters

按**解法实际必需**的章节标注，只标真正用到的章，不要只标最难的一章，也不要把无关章补进去。无法判断时可留空（留空不报错，平台会用 `tags` 做保守估计）。代码见附录 A。

### 5.4 source 与 source_category

| 试卷类型 | `source` 写什么 | `source_category` |

## 7. 交付前自检清单

逐条确认，全部通过再交付：

1. 试卷中的每道题都有一个 MD 文件，题号连续且不重复；卷首说明、卷末答案没有单独成文件。
2. 每个文件第一行是 `---`，第二行 `---` 已闭合，11 个字段名逐字正确；`title` 与 `id` 一致（年份＋试卷名＋题号），不是知识点。
3. `question_type`、`difficulty`、`tags`、`chapters`、`source`、`source_category` 的取值都在本规范给出的枚举内。
4. 每个文件都有完整转写；全文搜索「截图」「见图」「略」「此处为图片」，确认没有占位文字替代内容。
5. 每个 `$`、`$$` 都成对；没有 `\(`、`\[`。
6. `content:`、`answer:`、`solution:` 三段标记顶格、顺序正确，正文中不出现顶格的同名开头行。
7. 选择题：A～D 四个选项标记齐全，每个标记前是行首或空格，没有把四个选项拼进同一个公式；选项排版不用管，平台会自动处理。
8. 填空题空位是连续下划线；解答题小问编号写在行首，形式为 `（1）` / `（i）` 一类。
9. 标点符合 §3.2：中文语句用中文标点、句末是全角句点 `．`；公式里的逗号、句点、括号是英文半角，没有全角标点混进公式；没有用空格手工对齐、缩进、补空行。
10. 每个图片引用都能在同文件夹找到同名文件；不需要配图的题目没有图片引用。
11. 没有外链（http/https）、绝对路径（`/...`）、`../`、`data:`、HTML 标签。
12. 答案与解析只来自原卷；原卷没有的，两段留空。
13. 材料段 `:::material` 与 `:::` 成对、独立成行。
