# “讲给我听”的原文追问与停止对照（2026-10-02）

入口仍是题目页的“检验我是否真正理解”及已有自然语言同义请求。此次按 03/05/06/07/09/10 核对：原代码已有清楚时停止、编辑中取消与失败保留输入，但追问只数问号，未说明核对目的、未引用学生原话，已展示反馈也不随解释修改而过期。

四个基线故障回复均被旧解析器接受：缺少原文依据、反馈里另问一个问题、引用学生本次没有说过的参考解文字，以及将多个 probe 对象放入数组。它们分别由 TB13、TB07、TB05、TB08 固定为拒绝对照。这里的“拒绝”是协议或来源检查，不判断学生数学上是否错误。

当前模型输出仍使用 `status / feedback / nextQuestion`，新增单个 `probe`：

```json
{
  "status": "needs_probe",
  "feedback": "平方之前的等价条件还没说明。",
  "nextQuestion": "平方之前需要两边满足什么条件？",
  "probe": {
    "kind": "condition",
    "sourceQuote": "两边平方",
    "purpose": "核对平方变形的等价条件"
  }
}
```

`kind` 为 condition/reasoning/reading/method；引用 1–80 字，必须逐字出现于本次提交的解释，不能来自题干、参考解或旧反馈；目的 120 字内且不另问问题。反馈为 200 字内陈述，追问为 200 字内的单个字符串，最多一个问号。未知额外字段、数组、多对象、错引和缺目的均拒绝并保留输入。`clear` 必须无追问、probe 为空；保留旧 clear 回复省略 probe 的兼容形式。模型需遵守新提示协议，旧 needs_probe 回复缺少 probe 时会显示可重试错误。

回复卡保留原文，显示“你的原话”“这次只核对”，仍标为未经工具验证。明显答案守卫检查反馈、问题、引用及目的全部字段。引用只证明来源一致，不能证明其支持模型结论、条件必要或问题有教学价值。

测试文件 `frontend/src/features/ai-assistant/teachBackProbeEval.test.js` 从真实 Context Engine 和 Prompt 运行上述样本，检查当前解释保留、参考解排除、来源/目的字段与停止行为。模型回复均为合成，不证明真实模型能找准缺口或正确选择 clear；两个可行路线样本只固定人工期望与回复展示契约。

解释反馈、用户提交及重试操作现在绑定当前学习焦点和单调解释修订号。编辑后旧反馈明确过期，替换其操作为“按当前解释重新提交”，不进入后续聊天上下文；A→B→A 和换焦点不能复活旧反馈。进行中的旧回复继续被取消和丢弃。当前解释与反馈只留在页面内存，不新增长期学习事件、掌握分或服务器会话。

验证：177/177 前端单元测试、扩展 `tests/teach-back.browser.test.cjs`、主助手浏览器回归与生产构建通过。页面覆盖原文/目的显示、单卡追问、清楚时停止、编辑后过期及历史排除、同文回退、错引重试、A→B→A 迟到取消和自然语言入口。测试使用已安装 Edge、模拟 Provider 和本地页面，没有真实付费模型调用。

限制：精确引用不保证数学判断或提问相关性；单对象与问号数不能识别所有无问号复合任务，题目条件核验、真正的最高价值缺口和 clear 质量仍需真实模型与教师/学生评测。阅读样本是文字模拟，未验收真实 OCR。后续最小增量应让学生明确回答本次追问，再绑定补充解释重检；当前尚没有多轮 Feynman 状态或重复问题的语义检查。
