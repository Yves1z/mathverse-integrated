# Math Agent 人工评测题库 v0.1

本套材料是开发环境专用的原创题，不冒充高考真题，也不写入正式数据库。浏览器入口：`http://127.0.0.1:5173/math-agent-eval`。题目页面为 `/problems/MATEST001` 至 `/problems/MATEST004`。测试样例和人工判据同时显示在评测入口；点击“复制作答”后，到对应题目页的 AI 助手中粘贴。

## 测试前

1. 在项目 `frontend` 目录运行开发服务器，打开上述入口。
2. 题目页打开 MathSea AI 助手，选择自己要评估的厂商，自己输入 API Key，再点“测试连接”。不要把 Key 贴到评测记录中。开发环境的模型请求经本机 Vite 代理转发至已允许的官方 HTTPS 厂商地址。
3. 优先不要展开题目侧栏的“显示答案”；否则它可能影响你判断提示是否提前泄露，但当前 Agent 的 Hint Context 本身不会传参考答案。
4. 用题目页的“返回人工测试题库”链接在同一标签页切题；Key 只在该页面内存中，新标签页或刷新后需重填。每套用例建议清空当前对话。记录模型名称、响应耗时、是否正确、是否过度提示、是否标明未验证，以及实际回复。模型输出有随机性，关键用例可重复三次。

目前后端与数据库若未启动，题目页的收藏、题单等非 Agent 功能可能报错。这四道题由开发环境离线题目兜底提供；AI 模型测试仍需本机开发服务器可访问所选模型厂商及你自己的有效 Key。站内手写/草稿箱不属于本轮评测入口；这里的“作答”应粘贴到 AI 助手的文字草稿框。

## 用例与主要能力

| 用例 | 题目 | 示例作答类型 | 主要检测点 |
|---|---|---|---|
| E01 | MATEST001 参数与正根 | 临界点处结论错 | 第一处实质错误、重根与不同根、分类讨论 |
| E02 | MATEST001 参数与正根 | 更早的代入计算错 | 不被后续错误结论吸引，先定位第 2 步 |
| E03 | MATEST001 参数与正根 | 无草稿，请求提示 | 最小有效帮助、不提前透露参数分界或整题解法 |
| E04 | MATEST001 参数与正根 | 对极值和正根的错误解释 | Teach-back 只追问一个高价值问题，不伪造掌握结论 |
| E05 | MATEST002 不放回抽样 | 条件概率分母错 | 区分条件样本空间、保留前两步正确进展 |
| E06 | MATEST002 不放回抽样 | 约分错 | 识别 `18/64≠3/8`，不虚称组合计算已被工具验证 |
| E07 | MATEST003 椭圆弦与面积 | 正确的几何路线 | 尊重非标准但完全正确的路线，避免误报 |
| E08 | MATEST003 椭圆弦与面积 | 漏绝对值及另一分支 | 定位第 1 步、识别面积非负和漏情况 |
| E09 | MATEST004 对数函数零点 | 导数方程倒数写反 | 定位第 2 步，防止后续错误传播 |
| E10 | MATEST004 对数函数零点 | 明确索取解答 | 尊重直接求解意图，给出准确完整解答 |
| E11 | MATEST002 不放回抽样 | 条件样本空间错在前，算术错在后 | 先指出第 2 步的条件分母；第 4 步的可验证算术错误不能抢先展示 |
| E12 | MATEST004 对数函数零点 | 定义域错在前，算术错在后 | 先指出第 1 步的 $\\ln 0$ 无定义，不跳到第 3 步 |
| E13 | MATEST002 不放回抽样 | 前两步可行，第三步算术错 | 保留前两步路线，只把第 3 步等式标为工具已验证错误 |
| E14 | MATEST001 参数与正根 | 真算术等式后接无依据结论 | 不把第 1 步的真等式当成路线正确的证据；指出第 2 步缺少推导 |

题目的完整题干、正确答案和完整解析均位于 `frontend/src/config/mathAgentEvalProblems.js`；逐字可粘贴的错误/正确作答及人工判据位于 `frontend/src/config/mathAgentEvalScenarios.js`。以页面上的“人工核验”作为行为要求，不要求模型使用固定措辞。

## 建议追加的跨题测试

- 先在 MATEST001 问“再提示一点”，再切换到 MATEST002 问“这题的条件是什么”：回复不应混入前题的参数 $a$ 或提示状态。
- 在 MATEST003 选择解析中的某一步，再点“解释这一步”：应只解释选中步骤；清除选中后再请求，则应恢复当前整题焦点。
- 发送一个请求后立即停止或换题：旧回复不得写入新题对话；重试应保持当前输入。
- 在 E07 后追问“这个方法可行吗”：应认可几何路线，不因为与参考解法不同而强制换法。

## 旗舰模型对照方式

依次选择 `deepseek-flash`（对照）、`deepseek-v4-pro`、`qwen3.8-max`、`kimi-k3`，在相同的“标准”模式下跑 E01–E14；随后将 E01、E07、E08、E09、E11–E14 与“比较解法路线”在“深度”模式下重测。每次只使用所选厂商对应的 Key，切换厂商后重新填写。Kimi 预设使用国际开放平台的 Key，不能混用中国大陆区域的 Key。不要把 Key 记录在评估表。

每个用例至少记录：模型与模式、数学正确、是否找到第一处障碍、所引草稿原文是否来自定位步骤且支持判断、是否保留可行的学生路线、是否提前泄露答案、结构化响应是否可读、耗时和 Token。逐字引用只能核对反馈确实引用了该步，不能证明模型的数学判断正确；E11、E12、E14 仍须人工检查前提、推导和第一处障碍。先逐项判断严重错误，再比较总体表现；不要仅凭“解释更长”判定模型更强。若没有有效 Key 或余额，该模型标为“未实测”，不能计入排名。
