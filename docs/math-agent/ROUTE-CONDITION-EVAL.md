# 当前路线的单条件核对：失败与对照（2026-10-06）

## 差距和可见闭环

依据 00/02/03/05/07/09/10 核对：上一轮路线卡已有原文线索和待补条件，后续只能进入通用草稿，无法独立核对某条路线的一项声明条件。

当前入口：**比较解法路线 → 核对这条路线的条件 → 选适用/待补条件 → 可选说明 → 提交条件核对**。选择本身不调用模型。有待补条件时默认选它；缺少这一字段的路线只能选择适用条件。条件及路线均为 AI 初步建议，学生保留方法选择权。

缺材料或读法不明确时显示一个补充问题，“补充这个条件”只聚焦独立说明框；addressed 结束这次局部反馈，不显示新问题或自动推进草稿。取消保留说明但解除目标，换题/账号清除说明。局部编辑与反馈只在本页内存中，不恢复调用或旧判断。

明确自然请求如 `核对第2条路线的待补条件：我想限定区间。` 使用最新的当前路线卡，并进入相同意图。否定、讨论措辞含义和直接完整解答不被这一规则重定向。缺少当前路线图、编号越界或条件不存在时提供重新比较出口，不发送旧目标。

## 领域契约

| 对象 | 当前约束 |
|---|---|
| 选择目标 | mapId、method-N、范围/来源修订号、路线名、conditionKind、声明条件原文、该路线的来源线索；冻结后用于本轮快照 |
| 发送边界 | 所选名字、一个条件字段和线索、题干/当前步骤及最多两段紧邻前文、选填说明（≤1000 字）；其他路线、概述、取舍标准、首步、成本、换路信号、旧提示正文、历史、草稿、参考解和未来步骤排除 |
| 请求预检 | 完整当前 map schema、地图 ID、路线/条件/线索逐字一致、当前页面/焦点的 canonical scope、预期来源 revision；有来源时原文仍须存在 |
| 结构化输出 | 仅 routeId、conditionKind、conditionText、status、feedback、nextQuestion；目标三个字段必须逐字回显 |
| 局部反馈 | feedback ≤240 字且无问号；nextQuestion ≤200 字、最多一个问号；addressed 不提问，needs_input/uncertain 必须有问题 |
| 来源与状态 | AI 初步反馈，未经数学工具核验；无 mastery patch、数学 verification 或提示揭示推进 |
| 失效控制 | 地图/路线/条件及单调本地 revision 绑定反馈、错误、取消和 retry；编辑/改选/取消/范围变化后过期，A→B→A 不复活 |

字段里的复合条件没有自动拆成语义原子；一句话中多件问题也不能仅靠问号数识别。原文存在只证明来源，模型 echoed target 也只证明回显一致。

## 试错、修复和再次验证

1. 新领域测试 11/11 首轮通过。新页面旅程先因测试使用不存在的“消息输入框/发送消息”标签超时；按原 UI 的 placeholder 和“发送”修正定位，产品控件未改。
2. 内部 Context 检查发现先前提示正文仍会保留在 tutoring 字段，虽然条件 prompt 并未渲染它。局部请求现在同时排除这一内部正文，并加入保留旧提示的阴性对照。
3. 检查共享取消路径发现取消通知的 retry 未带目标。新增浏览器断言真实复现失败：换路线后通知仍只有“路线条件核对已取消…按当前上下文重试”，没有过期标记。这个入口可能把旧操作重新作用于新条件。
4. 修复：activeRequest 留存本轮 routeConditionRef；取消通知和 retry 同时携带它。换路线/说明/条件后，单调 revision 让两者过期。再次运行同一失败对照通过。增加主动“停止”对照：目标没变可重试同一条件；迟到回复隐藏；随后取消时停止通知的旧 retry 也过期。

新增 `frontend/tests/route-condition.browser.test.cjs` 验证实际页面与模拟 relay payload：不调用模型的选择、默认待补、局部内容排除、选填说明、一个追问、聚焦补充、addressed 停止、uncertain 读法、切条件、服务故障原目标重试、编辑后旧重试失效、错误回显拒绝、答案隐藏、路线 A→B→A 的迟到回复、取消通知旧重试、主动停止/原目标重试/迟到回复、取消保留说明、自然选择、关闭发送→恢复后仍过期、无有效 map 不调用，以及 390 像素布局。无浏览器 pageerror。

## 质量边界和下一步

所有 Provider 输出为模拟，未调用真实模型、未执行教师/学生或真实触屏验收。结构、目标回显、原文匹配和安全取消不能证明条件必要/充分、addressed 的数学真假、问题是否必要或学生能独立继续。模型可能漏掉前提、给错误肯定或用别的措辞泄露；现有 guard 仍是有限明显答案检测。

下一步建立单条件核对的成对失败样本：已回应/仍缺区间/与明确题设冲突/读法不确定，记录错误肯定和不必要追问。先复现具体失败；确能在明确假设下证明的窄类型再设计工具，未知继续保持未验证。完整方法图、自动证明、题库方法检索和长期方法画像仍在后续范围。
