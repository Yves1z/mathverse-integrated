## 工具契约与可证明范围

`verify_interval_condition` v1，确定性、无外部权限、低成本、100ms 声明预算。实际执行是长度受限的文本解析与 BigInt 分数比较；无任意代码、符号求解、浮点近似或生产采样。

输入对象只接受：

| 字段 | 限制与来源 |
| --- | --- |
| problemStatement | 当前题干文本，最多 6000 字 |
| conditionText | 所选 AI 条件原文，最多 160 字 |
| readingUncertain | 可选布尔；true 立即 unknown，错误类型拒绝 |

仅支持一个 ASCII 字母变量的实数区间：`x∈[a,b]`、开区间/半开区间、`x<k` / `x≤k` / `x>k` / `x≥k`、升序双边不等式 `a<x≤b` 等。有限端点是带符号整数（最多 9 位）、至多 6 位小数或整数分数（分子最多 9 位、正分母最多 6 位且非零）；±∞ 只能在正确方向的开端点使用。非空单点闭区间可支持；空区间、反向区间及闭无穷端点 unknown，避免空集上的虚假成立。

可识别单层成对 `$...$` 与有限 `\in`、`\le`/`\leq`、`\ge`/`\geq`、`\infty`，以及明确等价的 −/＞/＜/≤/≥。其他 LaTeX、未知端点、并/交、符号常数、分支、复合/假设语句、不同变量、未配对数学定界符和执行表达式均不支持。数字间空白不能把 `1 2` 静默拼成 `12`。

题设必须从 `已知`（可接 `实数`）开始，紧跟一个完整受支持范围。区间内部逗号不能截断题设。**题设尾部采用封闭语法**：仅允许空尾部/标点，或“讨论/研究”及可选“单调性/差值符号/符号”；其他内容全部 `qualified_context` unknown，包括合法但更复杂的普通题目。它是保守范围限制，不是一般题干语义解析。不会只抓开头而忽略后面的否定、撤销、猜测或其他假设。

输出结构：tool/version/scope、status、relation、reason、variable、规范化 checkedClaim、assumptions、expectedClaim。`expectedClaim` 在区间工具中表示题设范围；范围不是模型建议或标准答案。分数内部精确计算，输出不含 BigInt 并可 JSON 序列化。

设非空题设范围为 S、候选条件范围为 T：

| 关系 | 结果 | 可得结论 |
| --- | --- | --- |
| S ⊆ T | valid / subset | 该题设范围内所选区间条件成立 |
| S ∩ T = ∅ | invalid / disjoint | AI 候选条件与题设范围冲突 |
| 部分重叠 | unknown / overlap | 尚不能核对整个范围；不否定子区间上的可能路线 |
| 缺少支持范围、语法/读法/分支等未知 | unknown | 没有证明，也不是学生数学错误 |

端点开闭直接参与包含与相交判断。工具不判断方法必要/充分、单调性本身、整个步骤/路线、学生说明或长期掌握。

## 最小用户闭环

`routeConditionReview.js` 先校验不可变 Context，再尝试既有差值工具和本次区间工具。假设只来自当前题干，学生自由说明、解析选择、OCR/手写内容和其他候选不升格为新题设。当前调用不接收原始图像或手写读法；工具的 readingUncertain 门禁已测，但本次没有实现从自由说明推断读法状态，更不能自动确认真实 OCR。

- valid/invalid：模型调用前本地结束。Verification 标为“已核验 · 区间条件”，带唯一所选条件/路线、题目/地图/快照身份、假设与版本/范围/关系。响应从 Context 重算，模型协议拒绝证明字段。冲突归于 AI 候选，仍保留候选与学生说明；可明确重新比较。
- 缺少支持范围且说明为空：本地显示 unknown，给一个围绕当前变量讨论范围的 Question 和“补充讨论范围”动作，不发送模型、不生成 Verification 或 error_location。模型虚构的肯定因此不能进入 RCQ04 这条路径。
- 说明已填写、部分重叠、分支/撤销/读法/其他语法未知：保留既有结构化模型路径及未验证警示。学生选择一个范围，不等于该范围是题目给定事实。

说明修改、路线/条件改选、来源或发送范围改变仍使用原单调修订号机制，旧反馈和操作过期；没有自动换路线、HintState/mastery 更新或新持久化格式。

## 试错、原因和再次验证

1. 首批 36 个独立期望区间样本与领域/集成测试通过；页面复核包含、冲突、重叠、缺范围追问及补充后继续。
2. 补加 IC37–39：“已知 x≥0，这项条件不成立 / 撤销 / 仅是猜测”。试错组三例实际输出均是 valid/subset，首例使测试失败。原因是提取开头后只用有限词语黑名单审查尾部，三种资格变化被遗漏。
3. 修复改成上述封闭尾部语法，三例全部 unknown，不展示数学证明。页面的撤销题设对照确认仍走未验证路径。
4. 数字分隔与正常多位数成对补测，最终 42 例：11 valid、4 invalid、27 unknown，全部符合独立期望。另用有限整数端点的 15 个非空区间形成 225 个区间对，以端点及各开放单元的完整成员见证独立核对三态关系。该测试 oracle 只用于这组有限实例，生产工具仍做精确比较。

原 RCQ 银行保持历史伪造回复：RCQ03/04 数学结果仍 unknown，但本地提问阻断其模型反馈；RCQ05/06 仍由差值工具处理。RCQ02 的多余追问、RCQ08 的错误读法肯定仍是两个未修复语义失败。passing contract 不计教学质量通过。
