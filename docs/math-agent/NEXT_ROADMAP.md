# Math Agent 功能细化路线图

Last updated: 2026-10-06
Status: planning（实施仍以 `MATH_AGENT_CONSTITUTION.md` 和 `docs/math-agent/` 的 active 规范为准）

## 目标和推进规则

按一个用户可见的学习行为一次交付一个闭环：明确入口和焦点 → 取得最小必要上下文 → 给出可辨来源的反馈 → 学生继续或纠正 → 失败可恢复 → 回归测试。前阶段的验收证据与未完成项必须先记录；用户要求继续建设时，可以推进独立且可本地验证的增量，但不能把尚未通过的数学质量门槛计为完成。数学质量需要人工/真实模型评测，不能用 mocked relay 或合成失败样本通过代替。

不为尚无入口的能力提前建设完整 Agent Runtime、通用数学引擎或长期画像。新领域逻辑保持 provider-independent；模型生成的数学判断与工具验证结果分开标记。用户明确要求完整解答时继续提供。

## 交付顺序与验收门槛

### 0. 固定现有可见闭环的质量基线（下一次实施前）

- **用户旅程**：题目页选择提示/检查/解释/解答，看到焦点和来源，得到反馈后能写下一步；失败、取消、换题或刷新后行为可解释。
- **交付物**：把 `MANUAL-EVAL.md` 的 E01–E10 与跨题/中断案例整理为可重复的评测记录；在用户自带有效 Key 的环境下记录至少一个真实模型的通过/失败样本及原始问题，不记录 Key。补一条“编辑草稿后重新检查”的浏览器回归。
- **通过条件**：mocked 回归全绿；真实样本明确区分已验证/模型判断、第一处错误、路线保留、提示泄露与失败恢复。真实调用不可用时标记“未实测”，不声称质量达标。

### 1. 文字草稿的可信第一处障碍闭环（首个功能增量）

2026-09-24 已完成第一个增量：反馈绑定题目、草稿身份和版本；修改后旧反馈标为过期并从后续聊天上下文中排除；修正动作选中原文步骤；模型路线/定位矛盾被拦截且可重试；算术错误显示真实工具核对结果。`attempt-revision.browser.test.cjs` 已覆盖提交→修改→重检、失败重试及过期反馈，单元测试 92/92、主助手/teach-back 浏览器回归和生产构建通过。

2026-09-25 已完成顺序核验增量：按原文步骤记录、冻结并校验工具证据；较晚的算术错误前若有步骤，先让模型只检查前序范围。前序有障碍或不确定则先处理前序；前序初步可行才展示算术错误，同时明确前序并非已证明。模型越界定位被拒绝，调用失败不会跳过前序直接返回后面的纠错。单元测试 98/98、扩展草稿浏览器测试、主助手浏览器回归和生产构建通过；浏览器使用同仓库单独启动的 Vite 避开本机冷启动超时，页面断言未更改。

2026-09-25 已补 E11–E14 混合推理 golden cases，分别固定“条件样本空间/定义域错误在前”“可行计算在前”和“真算术不能证明后续结论”的人工第一处障碍。模型定位到步骤时须引用该步原文短片段，输出和展示阶段均校验草稿版本、步骤及引用关系；引用只证明来源一致，不能证明数学判断。

阶段 0 的真实模型验收仍待完成，阶段 1 仍为部分实现。下一步用 E01–E14 对真实模型记录第一处障碍、引用是否支持结论、条件遗漏与路线保留，再根据失败样本决定下一个窄范围数学工具。依赖/frontier、模型是否真正找准障碍及数学路线质量仍未独立验证。

- **入口**：现有“检查我的思路”及草稿编辑器。先只覆盖已确认的文字/LaTeX 草稿，不接图片。
- **数据/处理**：原文与来源区间不可覆盖；每次提交绑定 `attemptId + version`。增量建立步骤顺序、依赖与当前 frontier；在支持范围内先运行确定性工具，再让模型解释未知部分。发现第一处足以影响后续的障碍便停止，保留可行的非标准路线。
- **输出/恢复**：指明步骤、依据、影响和一个可执行修改动作；工具未覆盖时明确“AI 初步判断，未验证”。修改后使旧结论失效，再次检查新版，不把旧版答案贴给新版。
- **通过条件**：E01/E02/E05–E09 覆盖“更早的错误优先、非标准正确路线不误报、算术错误有工具证据、漏情况不虚称验证”；浏览器测试提交→反馈→修改→重检和编辑中取消；错误步骤判正确作为阻断性失败。每增加一种数学工具，都有独立的正例、反例、边界/定义域样例。

### 2. 会话恢复与 Provider 契约（只支撑已存在入口）

**最近的阶段 0/1 补充证据（2026-09-27）**：已有 22 个可重现的合成失败/对照样本，覆盖精确引用、先后顺序、计数等式、定义域、条件样本空间和显式变量值的对数风险。当前观察为 2 个契约拒绝、10 个预期定位和 10 个保守警示；警示不计为数学定位正确。阶段 0 的真实模型质量验收和阶段 1 的通用第一障碍判断仍未完成；继续扩样与窄范围工具验证，不能宣称已消除真实模型误判。

2026-09-27 已完成第一个恢复增量：按账号在当前标签页保存文字草稿与最近提交版本，分开保留未提交的编辑；刷新重建原文步骤后再次检查，编辑提交递增版本，同文重检不递增。旧批改与进行中的调用不恢复；清除此题草稿可删除保存内容；保存失败显示备份提示。111 个单元测试、22 个合成样本、扩展草稿浏览器旅程、主助手浏览器回归和生产构建通过。此增量不等于正式 AgentSession、聊天恢复或服务器 checkpoint。验证范围见 `CURRENT_STATE.md`。

- **入口**：刷新后继续当前题、取消/重试，以及现有模型切换和额度控制。
- **交付物**：从正式会话、Hint State 和 Attempt 派生可恢复的当前学习目标；实现必要的 checkpoint、版本与幂等键。Provider Adapter 明示结构化输出、推理、视觉能力和失败类型；保留用户选定的模型与额度、BYOK 数据边界。
